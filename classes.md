# VALOR-JRORTC Coding Classes

Material form the VALOR JROTC coding classes during Summer 2026.


Python classes using a [Jupiter notebook](https://namrathaurs.github.io/software-training/lab/index.html).
Notebooks mix text with the class instructions and code that you can run, all in a single document accessible via browser.

The slides used during the classes:

* [Introduction to coding](docs/Class1-Introduction.pdf)
* [Scripts, Modules and Variables](docs/Class2-ScriptsModulesAndVariables.pdf)
* [Programming Styles And OOP (Objects and Classes)](Class3-ProgrammingStylesAndObjects.pdf)
* [Git concepts](git_notes.pdf)
* [Edit your GitHub profile](https://docs.github.com/en/account-and-profile/how-tos/profile-customization)

Some links with additional material:

* The [Python documentation](https://www.python.org/doc/)
* These classes use [Jupyter Lite](https://github.com/jupyterlite), a lightweight notebook running entirely on your browser thanks to [Pyodide](https://pyodide.org/en/stable/) 
* [Markdown](https://www.markdownguide.org/getting-started/) and a [using it on GitHub](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)
* [Introduction to Git](https://mambelli.github.io/git-novice/)


Some advanced topics we did not cover much during the classes:
